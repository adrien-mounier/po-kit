Point hebdomadaire : trois façons d'ouvrir un sujet

Le PO a retenu l'option C le 25 novembre 2026. Sa forme finale est l'exemple de la passation, où la valeur mesurée et l'avancement ont été revus ; ces trois pages restent comme trace.

La même semaine fictive (Example Bank), le même style, les mêmes quatre écrans. Seule change la façon dont le détail d'un sujet s'ouvre depuis le premier écran. Cliquer une image ouvre l'option : F11 pour le plein écran, puis cliquer un sujet. « Mémo de crédit » est chargé exprès, « Tableau de bord qualité » presque vide.

A · Sous la ligne

Le détail se déplie sous la ligne du sujet. Les autres sujets restent visibles autour.

Point fort
On ne quitte jamais la liste ; on voit où l'on en est
Point faible
Un sujet chargé pousse le reste hors de l'écran : il faut faire défiler

B · En fenêtre

Le détail s'ouvre dans une fenêtre au-dessus de la liste, qui s'assombrit derrière.

Point fort
Toute l'attention sur un sujet, sans rien déplacer
Point faible
La liste est cachée pendant qu'on parle du sujet

C · Vue pleine

Le sujet prend l'écran. La liste se réduit à une colonne à gauche, où l'on passe d'un sujet à l'autre.

Point fort
Fait pour parcourir les sujets un par un, avec le plus de place pour le détail
Point faible
La ligne d'aperçu de chaque sujet disparaît pendant le parcours

Dans chaque option : cliquer un sujet l'ouvre ; les flèches haut et bas passent d'un sujet à l'autre ; Échap referme. La molette ou la touche Page suivante passe à l'écran suivant. Rien n'est enregistré : ce sont des maquettes.
